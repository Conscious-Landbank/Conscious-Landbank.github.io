6️⃣Bind Wallet to Account (Multi-Wallet)

Test Flow:
  1. Log in → Navigate to account-settings.html
  2. Click "Bind Another Wallet" → Wallet selection modal appears
  3. Choose MetaMask or WalletConnect → Connection modal shows
  4. After connection → Signature verification modal appears
  5. Click "Sign Message" → Shows message preview with domain, email, wallet, timestamp
  6. Confirm signature → Success! Wallet bound to account
  7. Wallet appears in list with ✓ "Verified" badge
Features:
  • ✅ 1 Account → N Wallets: Bind multiple wallets to one email
  • ✅ Verified Badge: Shows verification status
  • ✅ Remove Wallet: Click remove button → Confirmation → Unbinds
  • ✅ Duplicate Detection: Binding same wallet twice → Shows warning
Rule: One wallet → one email only. Account can have many wallets. Transaction history filtered by bound wallets.

💡Testing Tips

  • Document Selection: Test all three document types (Passport, Driver's License, National ID)
  • Date Format: Use YYYY-MM-DD format for dates (e.g., 1990-03-15)
  • Expiry Date: Use a future date to avoid validation errors
  • Required Fields: First name, last name, document number, DOB, and expiry date are always required
  • Optional Fields: Address and nationality may be optional depending on document type
  • Validation: The form validates all fields in real-time - watch for green checkmarks ✓
  • Photo Upload: Use the "Upload Files" option to test file upload instead of manual entry
  • Camera Option: Use "Use Camera" to test the photo capture flow (works best on mobile)
