**Badge** — pill for financial direction, on-chain proof, and reserve status; never a brand-decoration color for money.

```jsx
<Badge variant="up">+250.00 hCAD</Badge>
<Badge variant="down">−100.00 hCAD</Badge>
<Badge variant="verify">Verified on-chain</Badge>
<Badge variant="reserve">Fully backed</Badge>
```

`up/down/neutral` are money direction (fin colors); `verify` is Verified Teal (proof); `reserve` is Reserve Gold ink. Pass `icon` for an inline-SVG glyph.
