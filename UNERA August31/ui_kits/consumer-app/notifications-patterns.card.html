Shown while any transaction is in flight so the user can navigate away and still see it. Owned by TxTracker.pill in unera-pages/tx-tracker.js. The page only supplies the markup #txPendingPill as the first child of .nav-right. Label + elapsed minutes update every 15s; clicking returns to the status screen. It resolves to complete (fin-up dot) or failed (red dot) for 4s, then hides. Always ships alongside a matching bell notification (level progressing) so the state survives a reload. Note the .tx-pill[hidden]{display:none} pairing: the pill is display:inline-flex, which would otherwise beat the UA [hidden] rule.
