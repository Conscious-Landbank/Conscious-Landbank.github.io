Transaction Tracker: the shared "pending" screen (FE-207 §B)

One implementation for every flow that can leave the user waiting: donate with crypto, buy hUSD with fiat, swap. Ship it from unera-pages/tx-tracker.css + tx-tracker.js. Never re-implement per flow. Rules: plain-language headline + ETA first (never a hash, never "12 confirmations"); confirmation depth is a secondary bar with a friendly label; named stages with one sentence each in Deep Blue (current) / --fin-up (done) / grey (upcoming); a reassurance block; a rotating While you wait card; a "What is happening?" expander in everyday language; a micro-fact line. States: running → delayed → done | failed. All motion is CSS-only and collapses under prefers-reduced-motion.
