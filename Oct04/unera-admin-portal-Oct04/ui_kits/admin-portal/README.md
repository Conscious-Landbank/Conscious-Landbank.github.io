# Admin Portal UI kit

The portal itself is a Design Component: `../../UNERA Admin Portal.dc.html` (data in `../../portal-data.js`, table primitive in `../../DataTable.dc.html`). This folder only registers it in the Design System tab and as a starting point.

Screens: Overview (attention queue) · Users & Wallets list → user detail (Overview, Wallets, Transactions, Huma Points, Audit history) · Transactions list → transaction detail (retry / trigger) · Reserve & PoR → snapshot (draft / submit / approve & publish / reject) · Humanity Centers list → center form (publish / unpublish / archive) · Huma Points (Accounts, Ledger, Claims, Rectifications, Configuration) · Settings (Admin users & roles, Token whitelist, Reason codes, Audit log) · Portal structure.

Use the role switcher (top right) to preview Super Admin, Huma / Stablecoin Operator and Viewer; the prototype bar toggles table states and resets demo data.
