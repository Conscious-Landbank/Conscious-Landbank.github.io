Flow 1 — Stablecoin Management

Dashboard and Wallet Hub: balance display, transaction history, quick actions, notifications, and history tabs. Covers all 6 sub-features from the feature tracker.

Sub-features

  • 1Display current stablecoin balances — KPI hero on Dashboard + portfolio rows on Wallet
  • 2View recent transactions with status (completed, pending)
  • 3Quick buttons for sending or purchasing stablecoins
  • 4Simple visual summaries of activity and balances
  • 5Alerts for transaction statuses — notification bell + inbox
  • 6Access donation and remittance history in one place

Legend

Happy path — main user journey
Destination screen — exits to this page
Edge case — alternate or degenerate state
Error or blocked state
Missing / stub — not yet implemented

Entry Points

  • →Post-login redirect
  • →Direct URL to dashboard-enhanced.html
  • →Direct URL to wallet-enhanced.html
